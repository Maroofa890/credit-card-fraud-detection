Credit Card Fraud Detection

Machine Learning in R | Project by Maroofa Sheikh

📘 Project Overview

This project applies machine learning techniques in R to detect fraudulent credit card transactions using the Kaggle dataset (284,807 records and 31 features). The goal is to identify fraudulent behavior while minimizing false alarms.

Key steps include data exploration, imbalance handling using SMOTE, model comparison (Logistic Regression, Random Forest, XGBoost), and performance evaluation through ROC-AUC and recall metrics.

📊 Dataset Information

Source: Kaggle Credit Card Fraud Dataset

  • Transactions: 284,807
  • Fraudulent cases: 492 (≈0.17%)
  • Features: 30 anonymized + Amount + Class

📊 Model Evaluation

Performance comparison across models:

Model Accuracy Precision Recall (Fraud) F1-Score AUC
Logistic Regression 0.98 0.82 0.70 0.75 0.97
Random Forest 0.99 0.90 0.78 0.84 0.99
XGBoost 0.99 0.92 0.81 0.86 0.995

The XGBoost model achieved the best balance between recall and precision, identifying over 80% of fraudulent transactions with minimal false positives.

💡 Conclusion

  • Handling imbalance via SMOTE significantly improved fraud recall.
  • XGBoost achieved highest AUC (0.995) and recall (0.81).
  • Such models can be deployed in real-time systems for transaction monitoring.
